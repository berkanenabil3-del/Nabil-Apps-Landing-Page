MobileManager

Solution professionnelle pour la gestion des boutiques de téléphones mobiles, des ventes, réparations et du stock.

Description

MobileManager est une solution professionnelle destinée aux boutiques de téléphones mobiles. Elle permet de gérer entièrement les ventes, les réparations, les achats, les accessoires, le stock, les clients et les fournisseurs à partir d'une interface moderne.
